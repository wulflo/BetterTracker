# Better Fitness Tracker 0.9.19

Release de mantenimiento centrada en el **paquete MSIX para Microsoft Store**.
No cambia el formato de la bóveda (`omega/`) ni el de las copias (`longlife/`);
los datos existentes se conservan intactos.

### Iconos de Windows

- Se generan las variantes `Square44x44Logo.targetsize-*` del icono con
  `scripts/prepare-store-icons.mjs`, incluidas las `altform-unplated` y
  `altform-lightunplated`.
- El workflow `store-msix` las copia al payload, genera `resources.pri` con
  `makepri` y verifica que el índice incluya las variantes `unplated` antes de
  empaquetar. Sin ese índice Windows dibujaba el icono con una bandeja de fondo
  y más pequeño en la barra de tareas y en Inicio.
- El mosaico de la app usa fondo transparente en `AppxManifest.xml`.

### Release y documentación

- El workflow de release exige que el tag `vX.Y.Z` coincida exactamente con
  `VERSION`; un push normal a `main` solo ejecuta CI y no publica nada.
- README, guía de contribución y licencias de terceros actualizados, con las
  URLs del repositorio apuntando a `wulflo/BetterTracker`.
