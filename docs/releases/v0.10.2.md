# Better Fitness Tracker 0.10.2

Release de documentación técnica y metadatos de distribución. **No cambia la lógica de la
app, el esquema de la bóveda ni los cálculos**; la bóveda sigue en `VAULT_SCHEMA_VERSION = 1`.

### Estructure y skills del repositorio

- Nuevo `docs/Estructure.md`: índice técnico de la app (arquitectura React/Tauri, los 18
  `invoke` frente a los 22 comandos Rust, modelos de datos, bóveda `omega`/`longlife`,
  motores de energía/composición/proyección, vistas, tema/i18n, firma y releases).
- Nuevo directorio `.opencode/` con las skills adaptadas desde SinNotas: `Estructure`,
  `Estilo UI`, `Guía de uso`, `Traducciones UI` y `Búsqueda incremental`, más el comando
  `/estructure-sync` para actualizar el índice tras cambios de código.
- Las skills reflejan la realidad de esta app: React en vez de DOM imperativo, ES/EN en vez
  de ES/EN/ZH, tokens `--primary*`/`--surface*`, `Select` de `components/`, CSP con
  `connect-src 'none'` y búsqueda de alimentos/códigos con límites y caché.

### Autor del instalador

- `bundle.publisher` = `wulflo` y `copyright` en `src-tauri/tauri.conf.json`.
- `authors` = `["wulflo"]` en `src-tauri/Cargo.toml` (Maintainer de `.deb`, Manufacturer
  de MSI). El MSIX de Microsoft Store ya usaba `wulflo` como PublisherDisplayName.

### Documentación

- `docs/VERSIONING.md`: tabla de artefactos con Android, ejemplo de `latest.json` a la
  versión actual y las cinco claves obligatorias del manifiesto (`--require-all`).
- README y README.es con la versión 0.10.2.

### Verificación

- `npx tsc --noEmit`, `npm test` (**92 pruebas en verde**), `npm run build` y
  `cargo check --locked`.
- `npm run tauri dev` comprobado por el mantenedor antes del release.
- Sin cambios en dependencias: los PR de Dependabot no se han fusionado en esta versión.
