# Better Fitness Tracker 0.9.20

Release centrada en la corrección del color de acento, la proyección corporal
y la documentación.

### Color de acento

- `BodyFigure.tsx` dejó de usar colores hex fijos (violeta) independientes del
  acento elegido; ahora consume variables CSS (`--primary-deep`,
  `--primary`, `--primary-strong`, `--primary-container`, …) para seguir el
  acento activo en todos los temas.

### Proyección corporal

- La tabla y el gráfico de proyección muestran 5 puntos (inicial, 3
  intermedios y peso objetivo) en lugar de ~12 semanas. El integrador diario
  de dos compartimentos se conserva; solo se muestrea la salida.
- Revisión del algoritmo de predicción: se mantiene la integración diaria
  (Hall/Forbes + termogénesis adaptativa) sin regresiones; 91 pruebas pasan.

### Documentación

- README y README.es actualizados con 3 capturas de pantalla.
- Checklist de continuación actualizado con las tareas realizadas.
